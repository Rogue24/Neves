# 00 Guide：Swift 宏学习地图

## 一句话先讲明白

Swift 宏就是“编译器在编译期间帮你写 Swift 代码”的工具。

你写一小段很明确的宏调用，编译器在 App 运行前把它展开成普通 Swift 代码，然后继续做类型检查、报错和编译。

## 生活类比

可以把宏想成“编译期自动填表员”：

- 你先给它一张规则明确的表。
- 它按照固定格式帮你补内容。
- 补完以后，这张表还是普通表格，别人可以继续检查。

宏不是魔法师，不是在 App 跑起来以后临时变东西；它更像开工前已经把模板文档填好。

## 推荐学习顺序

1. `01_Intro`：先知道宏是什么，编译期展开是什么。
2. `02_Freestanding`：从 `#jpStringify` 学会 `#xxx` 这种独立宏。
3. `03_Diagnostics`：理解宏为什么能把错误提前到编译期。
4. `04_Attached`：学习 `@xxx` 如何贴在类型上生成成员或扩展。
5. `05_OCCompare`：对比 Objective-C 的 `#define`，理解 Swift 为什么这样设计。
6. `06_WhenToUse`：最后学取舍，不能为了用宏而用宏。

## 你会学到什么

- Swift 宏和普通函数有什么区别。
- Swift 宏为什么是编译期能力。
- 什么是 freestanding macro。
- 什么是 attached macro。
- 宏如何发出编译错误。
- Swift 宏相对 OC 宏的优势。
- 工程里什么时候该用，什么时候应该忍住不用。

## 总原则

记住这两句话就够了：

- 重复到烦、规则稳定、错误能提前，才考虑宏。
- 看不见的复杂度，不要用宏藏起来。
