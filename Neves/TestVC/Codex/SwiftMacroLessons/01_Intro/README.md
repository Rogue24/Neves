# 01 Intro：宏是什么

## 一句话先讲明白

Swift 宏是在“编译期间”运行的小工具，它读取你的源码结构，生成新的 Swift 源码。

生成以后，编译器会继续检查这些代码，所以宏展开后的东西仍然要符合 Swift 的类型规则。

## 生活类比

想象你要做饭：

- 运行时：真正开火炒菜。
- 编译期：开火前备菜、切菜、称调料。
- 宏：负责把那些固定、机械、重复的备菜工作提前做掉。

所以宏不是“菜炒到一半突然变出调料”，而是“开火前已经把调料准备好了”。

## 最小代码

```swift
let result = #jpStringify(1 + 2)
print(result.value)
print(result.source)
```

## 展开后大概长这样

```swift
let result = (value: 1 + 2, source: "1 + 2")
print(result.value)
print(result.source)
```

这里最关键的是：`1 + 2` 没有变成运行时字符串解析。宏只是把“源码文字”也一并生成出来。

## Swift 宏有什么好处

- 少写重复代码。
- 把一些低级错误提前到编译期。
- 生成的代码仍然受 Swift 类型系统检查。
- 比脚本生成代码更贴近源码，也更容易被工具链理解。

## 不适合做什么

- 不适合隐藏业务逻辑。
- 不适合替代普通函数。
- 不适合处理运行时才知道的数据。
- 不适合让团队读代码时到处猜“这个宏到底偷偷做了什么”。
