# 02 Freestanding：独立站着的 `#xxx`

## 一句话先讲明白

Freestanding macro 是“不贴在任何声明上”的宏，常见形式是 `#xxx(...)`。

它可以出现在表达式位置，就像一个特别的函数调用，但它不是运行时函数，而是编译期展开。

## 生活类比

`#jpStringify` 像“拍照留底”：

- 你把一道算式交给它。
- 它保留算式本身，用来正常计算。
- 同时把算式的源码文字拍下来，方便调试和展示。

## 最小代码

```swift
let result = #jpStringify((3 + 4) * 2)

print(result.value)
print(result.source)
```

## 展开后大概长这样

```swift
let result = (
    value: (3 + 4) * 2,
    source: "(3 + 4) * 2"
)
```

## 为什么不用普通函数

普通函数只能拿到“值”，拿不到“你在源码里怎么写的”。

例如：

```swift
func stringify<T>(_ value: T) -> (T, String) {
    // 到这里已经只剩 value，看不到调用者写的是 1 + 2 还是 a + b。
}
```

宏发生在编译期，它看到的是源码结构，所以能生成 `source: "..."`。

## 适合用

- 调试工具。
- 断言工具。
- 需要同时保留表达式结果和源码文字的场景。

## 不适合用

- 普通计算。
- 普通格式化。
- 运行时才知道的数据。

能用函数清楚表达，就先用函数。
